# Variable Mass System (Rocket Simulation)

Лабораторная работа по вычислительному моделированию: программа для расчёта и визуализации траектории и динамики движения ракеты как системы переменной массы.

## Общее описание

Приложение моделирует вертикальный или двумерный полёт ракеты в гравитационном поле с учётом реактивной тяги (черех уравнение Мещерского), уменьшения массы по мере сгорания топлива и сопротивления среды. В начальный момент времени ракета находится на стартовой позиции с полным запасом топлива. (если его никто не украл)

**Результат работы:**
- графики зависимости высоты/координат, скорости, ускорения и массы ракеты от времени;
- отметки ключевых этапов полёта (таких как: момент полного выгорания топлива, точка апогея);
- отображение векторов скорости и реактивной тяги в выбранные моменты времени;
- подписи осей, легенда и автомасштабирование области построения.

**Входные параметры:**

| Параметр | Описание | Ограничения |
| :--- | :--- | :--- |
| `m0` | Стартовая масса ракеты с топливом (кг) | строго положительный, \(m_0 > m_{\text{dry}}\) |
| `mDry` | Сухая масса конструкции ракеты без топлива (кг) | строго положительный, \(m_{\text{dry}} > 0\) |
| `dmDt` | Массовый расход топлива \(\mu = \frac{dm}{dt}\) (кг/с) | строго положительный |
| `uRel` | Относительная скорость истечения газов из сопла (м/с) | строго положительный |
| `dt` | Шаг времени дискретизации расчёта (с) | строго положительный |

## Архитектура

Проект построен по шаблону **MVVM** на платформе **.NET 9.0 + Avalonia UI** и разделён на независимые сборки: **Model** (физические расчёты), **ViewModel** (логика представления) и **App / View** (графический интерфейс).

## Правила работы с Git

(основаня музыка данного раздела - "Джентельмены удачи")

- Основная ветка — `main` (только Император репозитория одобряет через себя коммиты и пуши - иначе четвертуют)
- Рабочая ветка — `development` (основная ветка рабочего продукта нашего творения) (кто посмеет критиковать - в темницу)
- Личные ветки участников — `draft-core` (расчётное ядро) и `draft-ui` (интерфейс и графики) (кто посмеет сделать шаг влево или шаг вправо в чужую ветку - уволен)
- Коммиты пишутся на английском языке в повелительном наклонении: `feat(core): add rocket thrust calculation`, `fix(ui): validate fuel mass input`. (не знаешь английский? - бан навсегда)
- Перед слиянием в `development` — обязательный Pull Request и одобрение тимлида (Императора репозитория. Бэкдоры и обходные пути или попытка сразу запушить в development - ЦРУ, КГБ и Интерпол вас найдут)
- **!!!!!!  Запрещено  !!!!!!** удалять ветки и склеивать коммиты (squash) при merge - вся история коммитов сохраняется для проверки преподавателем. (иначе покарают меня, а заодно и наш Триумвират)
