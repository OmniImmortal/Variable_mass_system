# Техническое задание: Моделирование движения ракеты (система переменной массы)

## 1. Цель лабораторной работы
Разработать кроссплатформенное настольное приложение на C# (.NET 9.0) с графическим интерфейсом на Avalonia UI для численного расчёта и визуализации полёта ракеты на основе уравнения Мещерского.

## 2. Физико-математическая модель
1. **Изменение массы:** на активном участке траектории ($t \le t_{\text{burn}}$) масса уменьшается линейно:
   $$m(t) = m_0 - \mu \cdot t$$
   где время работы двигателя $t_{\text{burn}} = \frac{m_0 - m_{\text{dry}}}{\mu}$. При $t > t_{\text{burn}}$ масса постоянна и равна $m_{\text{dry}}$, реактивная тяга равна нулю.
2. **Уравнение движения (Мещерского):**
   $$m(t)\frac{d\vec{v}}{dt} = \vec{F}_{\text{тяж}} + \vec{F}_{\text{сопр}} + \vec{u}_{\text{отн}}\frac{dm}{dt}$$
3. **Численный метод:** интегрирование системы дифференциальных уравнений с шагом `dt` (метод Эйлера — Кромера или Рунге — Кутты 4-го порядка) до момента падения ракеты на поверхность ($y \le 0$ после старта).

## 3. Распределение задач по веткам и сборкам

### 3.1. Расчётное ядро (`VariableMassSystem.Model` — ветка `draft-core`)
- Реализация классов входных параметров (`RocketParameters`), точки траектории (`TrajectoryPoint`) и решателя (`RocketSimulator`).
- Валидация физических ограничений ($m_0 > m_{\text{dry}} > 0$, $\mu > 0$, $u_{\text{rel}} > 0$, $dt > 0$).
- Вычисление ключевых показателей: максимальная высота (апогей), максимальная скорость, время выгорания топлива.
- Написание юнит-тестов в проекте `VariableMassSystem.Model.Tests` (проверка формулы Циолковского при отсутствии силы тяжести, граничных случаев).

### 3.2. Пользовательский интерфейс (`VariableMassSystem.App` и `VariableMassSystem.ViewModel` — ветка `draft-ui`)
- Панель ввода параметров ракеты с отображением ошибок валидации и готовыми пресетами (например, «Метеорологическая ракета», «Ступень РН»).
- Кнопки управления расчётом («Запустить расчёт», «Сбросить»).
- Область графиков (библиотека `ScottPlot.Avalonia` или `LiveCharts2`): отображение графиков $y(t)$, $v(t)$, $m(t)$ с отметкой точки выгорания топлива и апогея.
- Панель вывода итоговых численных результатов симуляции.

## 4. Требования к коду и сдаче
- Стек: .NET 9.0, Avalonia UI (паттерн MVVM, отсутствие расчётов в `.axaml.cs`).
- Чистая сборка всего решения `VariableMassSystem.slnx` без предупреждений и ошибок.
